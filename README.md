An entry for the [make.fun](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76) "One Line to Your Younger Self" bounty. `main.ts` (Node 22, standard library only) writes one line its writer would send back to their younger self to `/output/entry.txt`:

> Your father's handwriting looks exactly like yours now.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
